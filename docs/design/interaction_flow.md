# 交互流程（C02/C05）

负责人：人员三（C）。目标是让“选条件 → 看差异 → 落到一条原始记录”这条链每一步都可见。

## 主流程（一条完整演示）

1. 页 2 选择高频职位（点代码按钮）→ 焦点职位与比较集合同时更新。
2. 页 1 点选 2～4 个地区散点 → 地区结构比较与相似地区随之刷新。
3. 左侧筛选栏固定经验代码（或学历代码）→ 三个页签的数字同步变化（同一条件签名）。
4. 页 2 看差异矩阵，点击某一对 → 读出各维贡献，判断“报价差异”占比多大。
5. 页 3 查看条件快照与明细，翻页找到来源行号，核对原串与解析状态。

## 状态规则

- 筛选状态唯一来源：`frontend/src/stores/filter.ts`。任何图不得自建条件副本。
- 切页保留条件；`清除筛选`/侧栏`重置`只清条件，不清比较对象；`region 页`点选再次操作可取消比较对象。
- 比较对象有上限：地区 ≤4、职位 ≤4；超过时淘汰最早选择（`shift`），并在界面写明当前数量。
- 条件变化时取消上一次请求（AbortController）并以序号丢弃过期响应，避免旧数据覆盖新条件。
- mock / real 由 `VITE_API_MODE` 决定；real 请求失败只显示错误态，**不回落**模拟数据，页头同时标出“真实接口”。
- 空结果与“薪资不可用”是两种不同状态：空结果显示提示文案，薪资不可用显示状态词，均不显示 0。

## 图表点击语义

| 位置 | 点击 | 结果 |
|---|---|---|
| 地区散点 | 点圆点（18px 容差） | 加入/移出比较对象 |
| 地区比较标签 | ✕ | 移出比较对象 |
| 相似地区代码 | 点代码 | 加入比较对象 |
| 职位代码按钮 | 点代码 | 设为焦点；再次点击当前焦点则移出比较 |
| 差异矩阵单元格 | 点单元格 | 显示该对各维分量与说明 |
| 明细表 | 上一页/下一页 | 翻页，条件不变 |
